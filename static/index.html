How it works

1. Open-Meteo geocodes the location and returns current conditions plus a 7-day forecast.
2. The Strands agent uses crop-stage guidance; the server keeps source weather facts separate from generated advice.
3. The agent returns a concise English explanation with limitations.
4. If a source or model fails, the app reports the failure instead of inventing values.
